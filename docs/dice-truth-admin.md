# 大话骰子与真心换真心后台管理

后台分别进入“大话骰子”和“真心换真心”。首页展示开启状态、最少开局人数、超时时间和各群当前对局；点击“编辑规则”修改配置。

| 配置 | 大话骰子 | 真心换真心 |
| --- | --- | --- |
| 开启开关 | 默认开启 | 默认开启 |
| 最少开局人数 | 默认 2 人，可设 2–10 人 | 默认 2 人，可设 2–10 人；升级保留已有设置 |
| 回合超时 | 默认 120 秒，可设 30–600 秒 | — |
| 提问超时 | — | 默认 300 秒，可设 30–3600 秒 |
| 回答超时 | — | 默认 600 秒，可设 30–3600 秒 |

配置统一对所有群生效。创建报名局同时受本玩法开启开关、群聊游戏总开关和群内该玩法开关控制；关闭玩法只禁止新建报名局，已有报名局或进行中的游戏仍可正常操作。

大话骰子在 `/开始` 时检查最少人数。真心换真心在 `/开始` 和 `/继续` 时检查最少人数。人数不足会按后台当前设置提示；保存新的超时时间不改写已经运行中的截止时间，从下一次行动或阶段开始生效。

“当前对局”按群展示对局标识、公开状态、轮次、参与者和截止时间。大话骰子显示当前行动位与公开叫骰，不展示个人骰子；真心换真心显示当前提问者与回答人数进度，不展示问题和个人答案内容。

点击某一对局的“强制结束”后需确认。系统按群、玩法类型、对局 ID 和配置版本校验，结束该局并刷新状态；不会误结束其他群或后续新开的对局。强制结束继续沿用现有结算、统计及群通知逻辑，未完成的轮次不会补成已完成轮次。

部署本功能前需运行数据库迁移 `20261006_100`。迁移保留既有超时时间和真心换真心人数设置，为已有配置新增默认开启状态，为大话骰子新增默认最少 2 人的设置。

## 大话骰子轮次与跳开规则

- 每次 `/继续` 开启下一轮时，先处理退出与中途加入，再将所有本轮参与者重新随机排序，编号从 1 开始，由新的 1 号首叫。随机结果有可能与上一轮相同。新的编号与顺序在群内公布，不再沿用上一轮顺序。
- 每次私聊发骰都会同时发送该轮万能点和失效规则。私聊 `/看骰` 也可查看骰子及万能点当前是否失效。
- `/开骰` 仍由当前行动者使用；未轮到的本轮参与者可发送 `/跳开` 抢先质疑。不能质疑自己的叫数，候补玩家不能跳开，两人局不存在可跳过的第三人。
- 跳开成功（实际数量小于叫数）：跳开者获得一次发令权，给叫骰者布置一个惩罚任务。
- 跳开失败（实际数量大于或等于叫数）：叫骰者和跳开前原定下一位行动者各获得一次发令权，各给跳开者布置一个惩罚任务。下一位以跳开处理时的当前行动位为准；没有有效的下一位叫骰者时不能跳开。
- 跳开使用相同的万能点与开骰判定，结束当前轮次并公开全场骰子。惩罚是任务提示，不扣摸鱼币。开牌、拆穿、败露与受罚统计仍按已结算轮次计算；双重惩罚算一次受罚轮次，原定下一位不额外计胜场。

以上优化无需新增数据库字段或迁移。
