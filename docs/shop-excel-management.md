# 商品 Excel 导入导出与管理

后台「商品列表」支持下载模板、导出全部商品、上传 `.xlsx` 并预览。搜索和分页不会限制导出范围；勾选「显示及导出已删除商品」可包含删除记录。

## 操作与字段

- 新增：商品编号和只读标识留空，由系统分配编号。
- 更新：按编号修改名称、描述、价格、库存模式、上架状态、分类、每日限购、职位及效果。
- 删除：可恢复的软删除；保留编号、系统标识、购买与使用历史，系统商品不会自动重新生成。
- 恢复：沿用原编号和配置，默认下架；再次编辑后上架。
- 跳过：不执行该行。已删除商品导出时默认跳过，回导不会意外恢复。

删除 Excel 中的一行不会删除商品。商品名称在全部商品（含已删除商品）之间必须唯一，批量改名支持名称交换。

价格为 0–999，库存为 0–99999；名称最多 64 字，描述最多 200 字，分类最多 32 字。每日限购 0 或留空表示不限，上限 99，同分类共用额度。最低职位填写现有职位序号或留空。

商品 ID、系统标识、配置版本、库存基准和删除时间为只读信息。配置版本与商品 ID 用于识别过期文件及错误匹配，不可手工修改。文件不是跨实例恢复备份，导入到另一数据库应使用空模板新增，不可直接套用编号。

## 效果配置

效果类型和适用参数由「效果字典」工作表列出，不执行任意脚本或代码：

| 效果 | 必填参数 |
| --- | --- |
| 无效果 | 无 |
| 赠送币 | 赠送金额（0–99999） |
| 随机奖励 | 最小、最大金额（0–99999，最小不大于最大） |
| 对话次数卡 / 多人游戏次数卡 | 增加次数（1–999） |
| 自愿场景公告 | 无，沿用现有收集场景与期望人数流程 |
| 授权场景 | 同类型场景模板、受邀人数（1–5） |
| 临时状态 | 同类型场景模板、持续分钟数（1–10080），目标数量固定为 1 |

不适用的参数必须留空。后台普通商品同样能配置已支持的效果，系统标识保持不变。效果修改不会绕过现有成人内容开关、目标检查及成年/场景授权流程。

未使用的背包商品在下次使用时采用当前效果；已经开始的流程保留名称、价格和效果快照，后续改名、改价、改效果不会改变当次流程。新购买和使用记录保留当时名称，旧记录迁移按现有商品信息回填。

## 校验与确认

上传不会直接修改商品。行级校验返回工作表、实际行号、列名、填写值、错误原因及修改建议，尽量一次展示全部错误。错误报告保留原始商品行并标记错误单元格，附加三列校验说明，可修正后直接重新上传。

文件级错误（格式、损坏、缺列、重复列、不安全 XML、宏/外链/嵌入对象）返回修正建议。仅支持不超过 5MB、2000 行的 `.xlsx`；不计算公式，公式和 Excel 错误值不能导入。导出文字强制按文本保存。

预览显示新增、更新、无变化、删除、恢复及错误数量，列出修改前后差异和持有人数、持有数量、未完成流程。删除、恢复、效果修改仅超级管理员可操作，并要求逐项勾选风险提醒。

已有库存默认不覆盖。开启库存同步后按 Excel 更新，要求确认覆盖风险；库存基准变化时重新导出或关闭同步。后台单商品保存仅在明确编辑库存时同步库存。

预览在数据库中保存，30 分钟内有效，绑定当前管理员。确认时再次检查权限、商品配置、相关库存、最终名称唯一性及删除保护。删除存在背包存量、未完成卡片流程、活动状态或待完成/失败可重试任务的商品会被阻止，请先下架处理存量；不自动清空背包、不退款。

整批执行使用一个事务，失败整批回滚。重复确认相同批次返回已完成结果，不重复新增或写入审计。审计事件记录操作者、批次、操作及修改前后信息。
