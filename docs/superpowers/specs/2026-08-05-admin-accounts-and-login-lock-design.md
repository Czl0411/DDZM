# 管理员账号与人工登录互斥设计

## 目标

在保留现有管理员 Token 作为超级管理员入口的前提下，支持多个普通管理员账号登录后台；人工登录桌面在任意时刻只允许一人操作，并在三分钟后自动安全收尾。任意已登录管理员都可以中断当前人工登录。

## 范围与原则

- 不改变群机器人、游戏经济或群消息处理。
- 不移除现有 `DZMM_ADMIN_TOKEN`；它仅代表超级管理员。
- 普通管理员使用用户名和密码；密码仅保存带随机盐的强哈希，不保存或展示明文。
- 不实现角色细分、登录续期、复杂审计页面或多人协作编辑。
- 登录桌面互斥状态由 PostgreSQL 持久化，不能只依赖浏览器前端状态。

## 身份与会话

新增两张表：

- `admin_accounts`：UUID、唯一用户名、密码哈希、启用状态、创建时间。
- `admin_sessions`：仅保存随机会话令牌的哈希、管理员 ID、过期时间与创建时间。

普通管理员通过 `POST /api/auth/login` 取得仅存于浏览器 sessionStorage 的会话令牌，并以 `X-Admin-Session` 调用管理 API。停用或删除账号后，该账号的会话在下一次请求立即失效。

现有 `X-Admin-Token` 保持有效，并被识别为 `super_admin`。超级管理员和普通管理员都能使用既有运营、玩法与人工登录功能；仅超级管理员可管理管理员账号。

管理员管理提供：列表、新增、重置密码、停用/启用、删除。禁止删除最后一个启用的管理员账号不在本期处理，因为超级管理员 Token 始终是独立的恢复入口。

## 人工登录锁

新增单例 `manual_login_leases` 记录：当前操作管理员、开始时间、北京时间到期时间。一次租约固定三分钟，不能续期。

流程：

1. 已登录管理员点击“开始人工登录”。服务端在同一事务内检查：Worker 为 `auth_required`，且没有未到期租约；随后创建三分钟租约并入队 `start_auth`。
2. 服务端状态接口返回租约是否存在、操作人用户名、到期时间和当前访问者是否为操作人。管理端所有人显示倒计时。
3. 只有租约操作人可以打开 noVNC、完成登录；其他管理员只能查看状态和点击“终止本次登录”。
4. 任意已登录管理员可调用 `POST /api/login/cancel`。服务端删除租约并入队可恢复常驻 Worker 的取消命令；当前 noVNC 会话立即失效。
5. 每次读取状态或执行人工登录相关 API 时，服务端先检查租约到期。若已过期，删除租约并入队同一取消命令。管理端倒计时到零时也主动刷新状态。
6. 正常“完成登录”同样删除租约，再入队 `finish_auth`。

取消和超时均复用 Worker 侧一个 `cancel_auth` 命令：关闭隔离桌面并启动持久化用户目录中的常驻无头浏览器。若登录未成功，Worker 自检后回到 `auth_required`，可重新发起人工登录。

## 并发与重复请求

读取接口可被多个管理员并发调用。所有改变状态的接口在服务端处理并发，前端禁用按钮仅用于降低误操作。

- 人工登录与浏览器重启使用全局登录租约；同一时刻只允许一个登录流程。
- 经济规则、活跃度规则、指令开关和回复模板返回资源版本号。保存请求必须携带读取时的版本；版本不匹配返回 `409`，管理端提示刷新后重试，绝不静默覆盖他人的修改。
- 管理员账号的用户名由数据库唯一约束保护；新增、停用、删除和密码重置均在事务中执行。停用或删除时同步撤销该账号全部会话。
- 上架物品沿用物品名唯一约束；接口将接受 `Idempotency-Key`，相同操作者与相同键的重复 POST/PATCH/DELETE 返回第一次完成的结果，不重复执行副作用。
- `Idempotency-Key` 记录保留至会话过期后，普通管理端会在每次写操作生成新键；网络重试复用同一键。

## 管理端体验

登录页提供两个入口：普通管理员的用户名、密码表单，以及超级管理员 Token 入口。登录后顶栏显示当前用户名和“超级管理员”标识（如适用）。

新增“管理员”左侧菜单，仅超级管理员可见。人工登录区域增加：

- 进行中时的剩余时间和当前操作人；
- 所有人可用的危险操作“终止本次登录”；
- 非操作人看到登录控制台按钮禁用，并说明“由 XX 操作中”；
- 到期、终止、完成后清理 iframe 与登录控制台 cookie。

## 验证

- 仓储测试：密码校验、停用/删除会话失效、租约创建互斥、三分钟到期释放。
- 管理 API 测试：普通管理员可登录及访问运营接口；普通管理员不能管理账号；超级管理员可新增、重置、停用、删除；租约操作人权限与任意管理员中断权限。
- 并发测试：同一幂等键不会重复执行、过期版本保存返回 `409`、并发创建同名管理员或物品仅有一个成功。
- Worker 测试：`cancel_auth` 关闭桌面并恢复常驻浏览器。
- 前端静态测试：账号入口、管理员菜单、倒计时和终止操作存在。
