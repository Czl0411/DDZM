# 记忆考核玩法设计

## 目标

新增群聊玩法“记忆考核”。机器人发布一段随机答案文本，在配置的展示时间后撤回；参与者必须凭记忆发送完全一致的答案。玩法提供单人闯关与双人对战两种模式，并复用现有摸鱼币账本与 Aikda 消息撤回能力。

## 范围与原则

- 使用北京时间计算日限制与超时。
- 全群同一时间只允许一场待报名或进行中的活动玩法。活动包括随机事件、单人记忆考核和双人记忆考核。
- 有活动时，新的玩法发起被拒绝，并说明当前活动名称和状态。
- 答案仅由已配置字符集随机生成；答案不含空格、换行或其他空白字符。
- 机器人发送答案后按配置延时撤回。只有撤回完成后，玩家答案才会被判题。
- 玩家答案必须逐字符完全匹配，大小写敏感；不做去空白、大小写折叠或模糊匹配。

默认字符集为 `A-Z`、`a-z`、`0-9`、`!@#$%&*_-`。管理端可修改字符集，但保存时必须拒绝空白字符。

## 指令与状态

| 指令 | 行为 |
| --- | --- |
| `/记忆考核` | 发起单人第 1 级挑战。 |
| `/继续` | 在单人本关答对后进入下一等级。 |
| `/收手` | 在单人本关答对后领取当前等级奖励并结束。 |
| `/记忆考核 对战` | 发起一场等待对手的 1v1 对局，并冻结发起人的基础奖池金额。 |
| `/加入` | 仅在双人记忆考核等待对手时加入，并冻结加入者的基础奖池金额。 |
| `/投降` | 双人对局中将本人标记为不合格；不退还已冻结金额。 |

单人状态为：`awaiting_answer`、`awaiting_decision`、`settled`、`failed`、`cancelled`。

双人状态为：`waiting_opponent`、`showing_answer`、`awaiting_answers`、`settled`、`expired`、`cancelled`。等待对手不是“已开始”，但仍占用全局唯一活动位。

## 单人挑战

1. 每名员工每个北京时间自然日最多发起一次。次数在成功创建挑战时占用；因系统发送/撤回失败而取消时归还次数。
2. 默认 5 级。默认答案长度为 5、7、9、11、13；默认各级可领取奖励为 1、2、3、4、5 摸鱼币。
3. 每一级生成新答案，发送、等待配置秒数、撤回，再进入 `awaiting_answer`。
4. 答对后进入 `awaiting_decision`，机器人仅接受该玩家的 `/继续` 或 `/收手`。
5. `/收手` 将当前等级的对应奖励一次性记入账本并结束挑战。
6. 任意错误答案立即失败，本局未领取的奖励清零，不产生扣币。
7. 通过最后一级后自动结算最后一级奖励，无需再输入 `/收手`。

单人奖励不是逐关预先入账；仅在收手或完成最终关时入账，故失败时无需反向扣款。

## 双人对战

1. 发起人执行 `/记忆考核 对战` 时冻结一份基础奖池金额；默认 5 摸鱼币。
2. 等待中的对局仅允许一名其他员工通过 `/加入` 进入。加入时冻结同样金额，随后立即开始。
3. 默认使用第 5 级长度作为对战强度，即默认长度 13；该强度为配置项，取值必须是现有单人等级之一。
4. 答案撤回完成后开始计时。平台收到的第一条完全正确答案获胜，赢家获得全部当前奖池。
5. 任一参与者每错一次，额外冻结配置金额进入奖池；默认 1 摸鱼币。该参与者累计错误达到配置上限时（默认 10 次）标记为不合格，之后不再接收其作答。
6. `/投降` 立即将该玩家标记为不合格。若另一方尚合格，另一方立即赢得当前奖池；若双方都不合格，系统回收奖池。
7. 若两名玩家均不合格，或撤回完成后经过配置的总时长仍无人答对（默认 10 分钟），系统回收全部奖池，双方均不退款。
8. 基础奖池与每次错误冻结均通过账本记录为冻结；赢家结算时将奖池作为正向收益入账，系统回收时冻结金额不返还且不产生正向收益。

## 配置与管理端

在“玩法配置”新增“记忆考核”区域，分为单人和多人两张卡片：

- 单人：每日挑战次数、撤回秒数、字符集、等级列表（等级、答案长度、奖励金额）。
- 多人：撤回秒数、对战强度等级、每人基础奖池、每次错误冻结金额、每人错误上限、作答超时分钟数。

保存采用现有版本号/防抖/按钮 loading 和成功或失败消息机制。数值必须为正整数；超时必须至少 1 分钟；字符集至少包含 2 个不同且非空白字符；等级长度与奖励均为正整数。

管理端的状态概览显示当前活动名称、模式、状态、参与者、奖池和到期时间。

## 可靠性与测试

- 建立持久化对局、参与者、答案状态与奖池账本记录；Worker 重启后由核心服务恢复计时与判题状态。
- 将“发送答案”“撤回答案”“开启作答”作为顺序步骤：只有 `message:recall` 平台确认成功，才允许作答。
- 对每个结算动作使用幂等键，防止并发答案与超时任务重复结算。
- 测试覆盖：字符生成、空白字符拒绝、每日限制、五级收手/继续、单人失败清零、双人入场冻结、首个正确答案、错题冻结与上限、投降、双重不合格、超时回收、全局活动互斥、重启恢复以及撤回失败时取消并退还占用次数/冻结金额。
