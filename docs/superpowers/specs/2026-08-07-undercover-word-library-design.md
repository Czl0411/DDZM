# 谁是卧底词库设计

## 目标

为群内《谁是卧底》提供稳定、可审核的固定词库，不依赖运行时 AI 生成。首批写入 900 套默认启用的词条，供后续游戏开局随机抽取。

## 范围

- 新增持久化词库表与数据库迁移。
- 写入 900 套平民词 / 卧底词。
- 每套词条标记所属主题和启用状态。
- 为后续管理端词库查看、编辑、停用预留数据字段；本次不新增词库管理界面。

不包含谁是卧底房间、私聊发牌、投票、淘汰、胜负结算或 AI API 接入。这些是独立的后续功能。

## 数据模型

新增 `undercover_word_sets`：

| 字段 | 说明 |
| --- | --- |
| `id` | 词条主键 |
| `category` | 主题分类 |
| `civilian_word` | 平民可见词 |
| `undercover_word` | 卧底可见词 |
| `enabled` | 是否可被后续新游戏抽取，默认启用 |
| `created_at` | 北京时间创建时间 |

词条要求：两侧均非空、同一词对不重复；顺序不同的同一对也不重复。白板身份没有词，不存为词库记录。

## 初始数据

使用九个主题，每个主题 100 套，共 900 套：

1. 办公职场
2. 饮食饮品
3. 日常用品
4. 地点场景
5. 交通出行
6. 影视娱乐
7. 动物自然
8. 校园生活
9. 互联网科技

词条为轻松日常题材，不写入露骨、侮辱性或高度地域化内容。迁移完成后所有词条默认 `enabled = true`。

## 使用约束

后续谁是卧底每局仅从已启用的词条随机选一套，并在开局时冻结至本局状态。平民取得 `civilian_word`，卧底取得 `undercover_word`，白板不取得词。词库变更不影响已开局牌局。

## 验证

迁移测试验证：

- 词库总数为 900；
- 九个主题各有 100 套；
- 全部默认启用；
- 词条两侧均非空；
- 词对（忽略顺序）无重复。
