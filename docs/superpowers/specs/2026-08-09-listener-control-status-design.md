# 监听控制与状态展示设计

## 目标

修复 Browser Worker 在临时认证或连接故障恢复后仍停止读取消息的问题，并让管理员在管理端查看、开启和暂停消息监听。管理员选择的开启或暂停状态必须在 Browser Worker 重启和服务器重启后保持。

## 当前问题

生产环境在认证检查失败时会进入恢复流程，将 `_listening` 设为 `False`。认证随后可以恢复为 `ready`，但旧代码不会同步恢复 `_listening`，导致心跳和接口看似正常、实际却跳过 `read_new()`。

管理端已经存在 `/api/worker/start` 和 `/api/worker/stop` 命令接口，但页面仍显示“群聊平台适配器尚未配置”，并永久禁用了两个按钮。现有状态接口只返回登录状态和队列数量，无法展示消息监听状态。

## 状态模型

核心服务持久化两个独立状态：

- `listening_desired`：管理员要求的目标状态。`True` 表示开启，`False` 表示暂停。该值在 Worker 或服务器重启后保持。
- `listening`：Browser Worker 当前实际是否执行消息读取，由 Worker 心跳持续上报。

初始默认值均为 `True`，以保持现有部署默认启动监听的行为。数据库迁移为现有 Worker 记录补齐 `True`。

管理员提交开始或暂停操作时，核心服务在保存目标状态的同时创建现有 durable Worker 命令。即使 Worker 在执行命令前重启，后续心跳响应仍会携带持久化的目标状态，Worker 会据此恢复正确状态。

## Worker 行为

每次循环继续先处理 durable Worker 命令。`pause_listening` 将目标暂停状态应用到本地，`resume_listening` 将目标开启状态应用到本地。

Worker 心跳同时上报登录状态和实际监听状态。核心心跳响应返回持久化的 `listening_desired`，Worker 将其作为最终控制源：

- 管理员目标为开启且认证正常：`_listening=True`。
- 管理员目标为暂停：无论是否发生重连，`_listening=False`。
- 管理员目标为开启但认证异常：实际监听为 `False`；认证恢复后自动变为 `True`。

临时读取、发送或认证错误仍进入现有浏览器恢复流程，但不能覆盖管理员保存的目标状态。

## API 与数据流

心跳请求增加 `listening`，心跳响应增加 `listening_desired`。`worker_instances` 增加对应的两个布尔字段。

管理端聚合状态 `/api/status` 增加以下安全字段：

- `listening`：当前实际监听状态。
- `listening_desired`：管理员保存的目标状态。

现有 `/api/worker/start` 和 `/api/worker/stop` 路径保持不变。开始操作把目标状态保存为 `True` 并创建 `resume_listening` 命令；暂停操作把目标状态保存为 `False` 并创建 `pause_listening` 命令。其他 Worker 命令不改变目标监听状态。

## 管理端交互

“消息收发”区域删除“适配器尚未配置”提示，显示一个监听状态和对应说明：

- `监听中`：登录状态为 `ready`，实际和目标均为开启。显示绿色状态，暂停按钮可用。
- `已暂停`：目标为暂停。显示黄色状态，开始按钮可用。
- `等待恢复`：目标为开启，但登录未就绪或实际监听尚未恢复。显示警告状态，可暂停。
- `状态未知`：尚无 Worker 心跳。两个按钮暂时禁用。

提交操作后按钮进入忙碌状态，接口成功后自动刷新。页面根据目标状态禁用重复操作，避免连续创建相同命令。浏览器登录状态卡片继续只表达认证状态，不与监听状态混合。

所有已登录管理员沿用现有权限，均可执行开始和暂停监听。

## 故障与一致性

- durable 命令执行失败时，目标状态仍保留；Worker 会在后续心跳中重新读取目标状态并应用。
- Worker 心跳暂时中断时，管理端保留最后状态，并通过现有最近心跳时间显示新鲜度。
- 部署采用先执行数据库迁移、再重启服务的现有流程，新增字段带服务端默认值，避免升级窗口内缺列或空值。
- 不修改 DeepSeek 调用、消息处理规则、发送通道或人工登录流程。

## 验证标准

- 临时连接失败后，只要目标状态为开启，认证恢复会重新读取消息。
- 管理员暂停后，重连、Worker 重启和服务器重启均保持暂停。
- 管理员开启后，重连、Worker 重启和服务器重启均恢复开启。
- 心跳、核心聚合状态和管理端页面显示一致。
- 管理端开始和暂停按钮只在对应操作有效时启用。
- 全量自动化测试通过；正式环境 18090 页面显示监听状态并可切换；测试消息能在开启时进入核心、暂停时不进入核心。
