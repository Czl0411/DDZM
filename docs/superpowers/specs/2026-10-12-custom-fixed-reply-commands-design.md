# 后台自定义固定回复指令设计

## 目标

管理员在现有「指令库」创建、编辑、停用或删除自定义斜杠指令。已监听群聊中的任意成员发送该指令时，Bot 在原群发送一条预设消息。回复可选文本、图片、群聊邀请卡或小说分享卡。图片由管理员在后台上传，不要求管理员寻找平台图片 URL。

成功标准：四种类型都经过现有 Core 出站队列和 Browser Worker 发出；配置保存后无需重启；私聊不触发；自定义指令不能覆盖现有业务指令；失败的图片上传不能改变正在生效的回复。

## 配置与匹配

- 每条配置含指令名、简短说明、启用状态、回复类型及该类型所需的固定内容。一条指令只对应一条回复，不支持变量、参数、随机内容或连续多条消息。
- 指令名以 `/` 开头，无空白，最长 32 字符；以去除首尾空白后的**整条消息精确匹配**。名称不得与内置指令、现有别名或特殊指令格式冲突。修改名称时也执行相同校验。
- 配置全局作用于所有已监听群聊；不按群分别配置。无需入职，群成员均可调用；Bot 私聊不识别自定义指令。
- 自定义指令保存在现有 `command_definitions` 中，以标记区分内置与自定义。新增的回复类型和内容字段仅用于自定义行；现有内置行、启停和模板保持原义。删除仅允许自定义行。已有 `/帮助` 使用启用的指令定义，因此会列出启用的自定义指令及说明。
- 群内其他玩法的指令拦截保持现状：公演、随机事件等正在限制指令时，自定义指令不绕过限制，也不改变游戏状态或经济数据。

## 四种回复内容

| 后台类型 | 管理员填写 | 保存后的内容 | 平台发送 |
| --- | --- | --- | --- |
| 文本 | 非空文字，最多 2000 字符，可换行 | 原文 | `type=text` |
| 图片 | JPEG、PNG 或 WebP 文件，最多 10 MB | 平台上传成功后返回的图片 URL | `type=image` |
| 分享群聊 | 当前 DZMM 站点的 `/invite/<邀请码>` 链接 | 邀请码 | `type=share, shareType=group_invite` |
| 分享小说 | 当前 DZMM 站点的 `/novel/<UUID>` 链接 | 小说 UUID | `type=share, shareType=novel` |

群聊的普通 `/chat?c=...` 链接不是邀请卡，保存时拒绝；当前平台前端将 `/invite/<邀请码>` 识别为 `group_invite`（[平台资源](https://www.ivorune.xyz/assets/04LafygP.js)）。小说链接沿用「公司的故事集」已有的解析与验证。未知域名、空内容、无效邀请码/UUID 或与回复类型不匹配的字段都不能保存。分享卡的 `resourceId` 只存提取后的标识，不把完整链接作为待发载荷。

## 图片上传与生效

后台沿用现有档案图片的异步模式，但用独立的自定义指令图片上传任务，不借用员工档案记录：管理员选文件后，Admin 验证 MIME、文件头和 10 MB 上限，暂存到仅服务进程可读的文件；Core 记录待上传任务；Browser Worker 用现有登录态和 `upload_image` 上传到平台，回写图片 URL 或失败状态，并删除已处理的暂存文件。页面轮询任务结果并显示预览或错误。

新建图片指令只有在上传完成、管理员点击保存后才生效。替换图片时，旧指令在新图上传期间继续保持原内容；若上传失败或管理员取消，新图不保存、旧内容不变。完成上传但未保存指令的任务记录可保留结果用于当次表单，不将临时文件保留在服务器。图片发送复用现有出站 `content_type=image` 与限速/失败处理。

## 后台与服务边界

- 「指令库」增加「新增自定义指令」入口。列表仍可搜索、分页、启停；自定义卡片显示类型、说明和当前内容摘要，并提供编辑、删除。编辑弹窗随类型显示对应字段；图片类型显示本地选择、上传状态和预览。
- Admin API 沿用登录鉴权；指令 CRUD 沿用配置版本和幂等约定，图片上传任务另按现有档案图片上传方式鉴权、查询状态。Core 负责名称/类型/内容校验和持久化，Admin 不单独实现另一套业务判定。
- 群消息先走现有游戏与活动路由；只有内置指令不匹配时才查询启用的自定义指令。命中后生成一条 `CommandReply`，在原群入现有出站队列。Worker 对 `group_invite` 增加结构化分享发送分支；文本、图片和小说沿用现有分支。失败、重试、限速与去重沿用出站机制，不增加绕过平台限制的发送路径。

## 验证

- 数据库迁移与仓储：内置指令不变；新建、改名、编辑、启停、删除自定义指令；拒绝内置及别名冲突、非法名称、无效类型与内容。
- 群消息：四种类型各产生一条正确类型和载荷的出站；跨已监听群可用；私聊、未监听群、停用或删除后不触发；带额外参数不触发；现有活动限制仍生效。
- 图片：合法文件上传并可预览/保存；大小、MIME、文件头错误拒绝；平台上传失败或编辑中取消不会替换旧回复；临时文件在任务完成后清理。
- Admin API 与页面：鉴权、配置版本、CRUD、类型字段切换、上传状态、保存后重开内容一致、列表操作仅对自定义行出现。
- Worker：群聊邀请卡使用 `group_invite` 与邀请码，小说卡使用 `novel` 与 UUID；不会把分享链接当普通文字发送。

## 不做

本期不做私聊触发、按群独立配置、未加 `/` 的关键词、指令别名、多消息连发、动态变量、随机回复、权限分级、定时推送或修改内置指令行为。部署与生产数据变更不属于设计确认后的自动步骤。
